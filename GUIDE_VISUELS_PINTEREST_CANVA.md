## 1. SETUP CANVA (5 min)

1. Crée un compte gratuit : [canva.com](https://www.canva.com) (ou connecte-toi si déjà fait)
2. Clique **« Créer un design »** → recherche **« Pin Pinterest »** → sélectionne **« Pin Pinterest »** (1000×1500)
3. **Important** : vérifie la taille dans le menu **Fichier → Réglages du design** : `1000 × 1500 px`
4. Passe le design en **Pro** ? NON — le gratuit suffit largement (on n'utilise que les outils de base)
5. Épingle ce guide si besoin — on repartira de ce design pour tous les visuels

> 💡 **Astuce Pro gratuite** : utilise les **modèles Canva** en cherchant « Pinterest product » dans l'onglet Modèles, puis adapte les couleurs/textes.

## 2. LES 5 RÈGLES D'OR

Un visuel Pinterest doit être lisible **en 2 secondes** sur un téléphone dans un flux défilant :

| Règle | Détail |
|-------|--------|
| **1. Gros texte** | Le titre = 40-60% de la surface. Minimum 60-80 pt pour le titre principal |
| **2. Peu de mots** | 5-10 mots max sur l'image. Le reste est dans la description |
| **3. 1 produit = 1 image** | Une seule photo du produit, nette, détourée si possible |
| **4. Contraste fort** | Texte clair sur fond foncé (ou l'inverse) — jamais de gris sur gris |
| **5. Identité visuelle** | Même style/police/couleurs sur les 70 = marque reconnaissable |

### Hiérarchie d'un visuel (du haut vers le bas)
```
┌──────────────────────┐
│  BANDEAU HAUT (10%)   │  Logo Affilimax + "2026" petit
│                      │
│  TITRE EN GROS       │  Le message choc (40-50% de la hauteur)
│  (3-5 mots clés)     │
│                      │
│  IMAGE PRODUIT       │  Photo du produit (30-40%)
│                      │
│  BANDEAU BAS (10%)   │  "Clique pour voir le prix" + note étoiles
└──────────────────────┘
```

### Polices à utiliser (Canva gratuit)
| Rôle | Police | Style |
|------|--------|-------|
| **Titre principal** | **Montserrat** ou **Poppins** | Gras (Bold), 60-80 pt, MAJUSCULES |
| Sous-titre | Montserrat / Poppins | Regular ou Medium, 28-36 pt |
| Bandeau + CTA | Montserrat | Gras, 24-30 pt |
| Chiffres/prix | **Lato** ou Montserrat | Extra Bold, 40-60 pt |

> Cherche-les dans **Texte → Ajouter du texte** : elles sont gratuites. Une seule famille de police par visuel = cohérence de marque.

## 5. TEXTES ACCROCHEURS

### Formules qui fonctionnent (titres sur l'image)
- « Le meilleur [produit] de 2026 » → *Le meilleur air fryer de 2026*
- « [X] vs [Y] : lequel choisir ? » → *Bose vs Sony : lequel choisir ?*
- « Le test honnête après [durée] » → *Le test honnête après 6 mois*
- « [Budget] : les meilleurs [produits] » → *Moins de 100€ : les meilleurs casques*
- « La liste qu'il faut sauvegarder » → *La checklist rentrée à sauvegarder*
- « Ne ratez pas le [prix] » → *Ne ratez pas le bon plan*
- « 2026 : le guide [thème] » → *2026 : le guide setup bureau*
- « [Nombre] fournitures indispensables » → *30 fournitures indispensables*

### Micro-textes d'appui (bandeau bas)
- « Clique pour voir le prix » 👉
- « Avis vérifié 2026 » ✅
- « Bons plans Amazon » 🛒
- « Testé & approuvé » ⭐
- « Comparatif honnête » 🔍

### Interdits
- ❌ Plus de 10 mots dans le titre principal
- ❌ Texte illisible (contraste trop faible)
- ❌ Fond chargé / image de stock générique
- ❌ Logo Amazon ou marques dans le coin (droit d'auteur)
- ❌ Pas de date (devient obsolète) — sauf « 2026 » qui est un mot-clé

## 6. WORKFLOW BATCH (70 visuels en 1h)

### Étape 1 — Crée 8 designs « parents » (10 min)
Un par thème : RENTREE, BUREAU/TECH, AUDIO, MAISON, CUISINE, SPORT, FINANCE/LIVRES, DIVERS.
Mets la palette, le gabarit et les polices.

### Étape 2 — Duplique (15 min)
Pour chaque thème :
1. Clique **« ... » → « Dupliquer »** autant de fois que d'épingles du thème
   - RENTREE : 10 copies | BUREAU/TECH : 19 | AUDIO : 7 | MAISON : 9 | CUISINE : 5 | SPORT : 6 | FINANCE/LIVRES : 9 | DIVERS : 5
2. Renomme chaque copie avec le N° d'épingle : `EPINGLE 01 - rentree`, `EPINGLE 02 - rentree`…

### Étape 3 — Personnalise chaque visuel (25 min)
Pour chaque copie, remplace **uniquement** :
1. Le titre (depuis le fichier `POSTS_PINTEREST_14JOURS.txt`)
2. La photo du produit (téléchargée depuis Amazon.fr — photo officielle du produit)
3. La note / prix si visible

> ⚠️ **Images** : les photos Amazon sont protégées par le droit d'auteur. Pour rester safe :
> - Rentreée/lifestyle (fournitures, bureau, cuisine) → utilise les **photos gratuites Canva** (Photos → "rentrée scolaire", "setup bureau"…) : plus sûres et souvent plus jolies
> - Produits tech précis (casque Bose, robot…) → capture d'écran de la fiche produit à faible résolution, utilisée uniquement comme illustration d'avis
> - Ne recadre jamais le logo Amazon dans le visuel

### Étape 3bis — Priorité saisonnière (rentrée)
Les 10 épingles **RENTREE** (jours 1-10 du calendrier) sont URGENTES : crée-les en **premier** (2-3 premiers jours de production), puis les autres thèmes dans l'ordre du calendrier.

### Étape 4 — Télécharge tout (5 min)
1. Sélectionne les 70 designs (Ctrl+A dans le dossier Projets)
2. **« Télécharger » → PNG → 1000×1500**
3. Sauvegarde dans un dossier `visuels_pinterest/` sur le bureau

### Étape 5 — Publie selon le calendrier (5 min/jour)
Ouvre `CALENDRIER_PINTEREST_14JOURS.txt` → pour chaque épingle du jour :
1. Téléverse le PNG correspondant
2. Copie TITRE + DESCRIPTION depuis `POSTS_PINTEREST_14JOURS.txt` (référence SOURCE)
3. Colle le LIEN (avec `?src=pinterest`)
4. Choisis le BOARD du thème
5. Programme à l'heure indiquée (9h, 13h, 17h, 20h, 21h30)

## 7. CHECKLIST QUALITÉ

Avant de publier chaque visuel, vérifie :

- [ ] Format 1000×1500 (ratio 2:3)
- [ ] Titre lisible en 2 secondes (gros, contrasté)
- [ ] 5-10 mots max dans le titre
- [ ] Photo produit nette et centrée
- [ ] Palette du thème respectée (cohérence de marque)
- [ ] Bandeau « Affilimax · 2026 » présent
- [ ] CTA visible (« Voir le prix », « Lequel choisir ? »)
- [ ] Pas de logo de marque tiers
- [ ] Lien de l'épingle = article correspondant avec `?src=pinterest` (épingles 69/70 : `?src=pinterest2` — ne jamais supprimer le paramètre)
- [ ] Description copiée depuis le fichier des épingles (avec hashtags)
