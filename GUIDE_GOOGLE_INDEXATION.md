## 📋 ÉTAPE 1 — Créer le compte Search Console (10 min, 1 seule fois)

1. Va sur **https://search.google.com/search-console** → connecte-toi avec ton
   compte Google (gmail).
2. Clique **"Ajouter une propriété"** → choisis **"Préfixe d'URL"**
3. Colle : `https://afflimax.onrender.com`
4. Méthode de vérification : choisis **"Balise HTML"** (la plus simple)
   → Google te donne un petit code (ex: `<meta name="google-site-verification" content="xxxx" />`)
   → **envoie-moi ce code** (ou mets-le toi-même dans `pub.html` dans le `<head>`)
   → je le déploie, tu cliques "Vérifier".

> Alternative sans code : tu peux aussi vérifier via le fichier HTML ou DNS —
> mais la balise HTML est la plus rapide avec nous.

## 📋 ÉTAPE 2 — Soumettre le sitemap (2 min)

1. Une fois la propriété vérifiée : menu de gauche → **Sitemaps**
2. Colle : `sitemap.xml`
3. Clique **Envoyer**
4. Google lira le fichier → verra les 166 URLs → commencera à les indexer
   (l'indexation complète prend **3 jours à 3 semaines** en général)

## 📋 ÉTAPE 3 — Vérifier le résultat (optionnel)

- Menu **"Pages"** (ou "Indexation" → "Pages") : tu verras le nombre de pages
  indexées monter progressivement.
- Menu **"Performances"** : les clics organiques apparaissent (c'est du trafic
  réel Google → tes futurs gains).
